# reference：從課程資料複製的小檔案

2026-11-25 使用者同意，把課程資料夾 `RCode4Text-20261005/data/` 裡的三個小文字檔複製進專案，方便程式直接讀取，也讓其他接手者看得到。其餘老師教材不放進專案，說明見 HANDOFF.md「老師教材的用途」。

| 檔案 | 內容 | 筆數（含第一行標題 word） |
|---|---|---|
| `stop_words.txt` | 中文停用詞 | 約 1,892 行（課程資料夾裡的 `stop-mac.txt` 內容與它相同，只複製一份） |
| `ntu-pos-mac.txt` | NTUSD 正面情緒詞 | 約 1,250 行 |
| `ntu-neg-mac.txt` | NTUSD 負面情緒詞 | 約 1,138 行 |

格式：UTF-8，第一行是欄名 `word`，之後一行一詞；兩份情緒詞檔的行尾混有 CRLF 與 LF，讀入後要去除空白與換行。

限制：來源與授權沒有查證，只確認是老師提供的課程資料，用於本課程專案。NTUSD 只有正負兩類，沒有情緒強度，且為通用詞表，對「斷更」「完結」「棄坑」這類小說用語可能判斷不準，使用前先抽查，不把字典結果當作立場的正式標籤。

## 使用前要先處理的問題（2026-11-25 檢查）

- **停用詞檔**含有「不」「沒有」「沒」「但」「但是」「不是」，這些否定與轉折詞對判斷立場很重要，直接使用會讓「不好看」失去否定。使用前先移除，再加入語料裡的雜訊詞。
- **NTUSD** 涵蓋不足：用 14 個與小說平台相關的詞檢查，只有「免費」出現（列為正面），「好看」「喜歡」「精彩」「爛」「難看」「無聊」「貴」「斷更」「棄坑」「完結」「卡文」都沒有。這只是小型的完全相同字串比對，不代表整份字典的涵蓋率。
- 作法：NTUSD 只當基準，另建小型補充詞表（從讀過的討論挑詞並記錄來源），再抽 30 則人工標註核對一致率；斷詞詞典（平台名與小說用語）必須自己做，老師的檔案沒有。
