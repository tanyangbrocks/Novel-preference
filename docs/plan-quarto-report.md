# Quarto 報告大綱與技術安排

*建立：2026-11-25　狀態：大綱已由使用者確認（照用），骨架已建於 `report/`*

## 為什麼先擬大綱

報告正文要等資料到位才寫得完，但**大綱要先定**：每一節回答哪個問題、用哪張圖、證據從哪來、現在資料狀態如何、做到什麼程度算完成。這樣蒐集時隨時能對照「這批資料要放在報告哪一節」，沒有對應章節的資料就不蒐集（見 [plan-research-flow.md](plan-research-flow.md)）。

## 3　寫作規則

- **先建骨架。** 每章先放標題、要回答的問題與「資料缺口」標記，資料到位的章節再填；缺資料的章節不要寫空話。
- **每個結論標證據。** 圖表附資料來源、期間、樣本數與分母；留言只放改述與連結，不放帳號。
- **結論強度。** 官方調查的「文學圖書」不能說成網路小說；網路討論只能說「在選定場域的討論中」；留言中的數字標未驗證。
- **用自己的話寫**，不模仿老師的口吻（使用者指示）；避免 AI 慣用句型。
- **簡報與規劃書同步。** 報告若改變了研究設計，要同步改規劃書、一頁大綱與簡報。
